Family Smart Calendar — 连接 Muse

让 Muse 帮你管理日历。先用你自己的 Supabase 账号登录一次（就是 App 里 登录用的那个账号），再把登录后得到的 refresh token 交给 Muse。登录一次 就行，Muse 会自动续，不用反复登录。

1. 登录

登录状态：正在检查…

已登录账号：—

家庭 ID：—

邮箱登录直接用 App 里注册的账号。还没账号？点“注册新账号”， 填邮箱、密码和名字就能注册（内测期间注册完直接登录，不用验证邮箱）。

Google / Apple 登录会跳到对应页面，登录成功后自动跳回本页。 如果点完报错（比如提供商还没开通），改用上面的邮箱登录。

注意：退出登录会吊销已交给 Muse 的 token，Muse 就写不了日历了， 需要重新连接。连好以后不要在这里点退出。

2. 复制下面这句话，发给 Muse

点下面按钮复制这句话，回到 Muse 对话里粘贴、发过去。Muse 看了就 知道是哪个 App、要干什么，会发给你一个安全采集链接。安全链接生成后， 回到这个页面，进行第 3 步。

3. 回到这个页面，复制 refresh token，粘贴到安全链接里

Muse 发给你安全采集链接以后，回到这个页面（它还在 Safari 后台开着， 不用重新登录），点下面按钮复制 token。再打开 Muse 发给你的安全链接， 把 token 粘贴进去，就完成了。不要把 token 发在聊天里，也不要截图发给别人。

注意顺序：先复制第 2 步那句话，再复制 token。每次只复制一个东西， token 最后再复制，不然会被顶掉。粘贴好以后，Muse 就能读写你的日历了。 这个 token 长期有效，Muse 会自己续；如果以后想断开，让 Muse 删掉它， 或者在这里点“退出登录”（会吊销 token）。
