Family Smart Calendar — 连接 Muse

让 Muse 帮你管理日历。先用你自己的 Apple ID 登录（苹果官方登录页， 支持 Face ID，Muse 不会看到你的密码），再把登录后得到的会话 token 交给 Muse。户主分三步；家人（管理员）多一个第 0 步，一共四步， 后面三步和户主完全一样。

0. 仅管理员（家人）先做这一步，户主跳过

如果你是户主，直接从第 1 步开始，不用看这一步。如果你是家人 （管理员，App 里能改日程），先打开 App 设置页，点「复制给 Muse 的设置信息」，把复制到的内容发给自己的 Muse。这是告诉你的 Muse： 写进谁的日历、哪个库。发完再从第 1 步开始，后面三步和户主完全一样。 只能查看的家人不用连接 Muse，Muse 也不能替你改日程。

2. 复制下面这句话，发给 Muse

点下面按钮复制这句话，回到 Muse 对话里粘贴、发过去。Muse 看了就 知道是哪个 App、要干什么，会发给你一个安全采集链接。安全链接生成后， 回到这个页面，进行第 3 步。不要把 token 发在聊天里。

3. 回到这个页面，复制 token，粘贴到安全链接里

Muse 发给你安全采集链接以后，回到这个页面（它还在 Safari 后台开着， 不用重新登录），点下面按钮复制 token。再打开 Muse 发给你的安全链接， 把 token 粘贴进去，就完成了。

注意顺序：先复制第 2 步那句话，再复制 token。每次只复制一个东西， token 最后再复制，不然会被顶掉。粘贴好以后，Muse 就能读写你的日历了。 会话放着不用大约半天就会过期；过期后 Muse 会请你重新登录一次， 还是上面这几步。
