Family Smart Calendar — 连接 Muse

让 Muse 帮你管理日历。先用你自己的 Apple ID 登录（苹果官方登录页， 支持 Face ID，Muse 不会看到你的密码），再把登录后得到的会话 token 交给 Muse。整个过程只要点两次按钮。

2. 把 token 交给 Muse

登录后点下面按钮，token 会复制到剪贴板。然后回到 Muse 对话， 把它粘贴到 Muse 发给你的安全采集页里，不要发在聊天里。

粘贴好以后，Muse 就能读写你的日历了。会话约两周过期； 过期后 Muse 会请你重新登录一次，还是上面这两步。
